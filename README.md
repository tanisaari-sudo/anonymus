# Anonymus

Два скрипта для анонимизации отчётов об археологических работах перед отправкой в нейросеть.

**Проблема:** отчёт содержит чувствительные данные — названия компаний-заказчиков, номера договоров, координаты, ФИО. Отправлять это в облачный ИИ нежелательно.

**Решение:** `anonymizer.py` заменяет все чувствительные данные токенами-заглушками (`[ОРГ_1]`, `[ФИО_2]` и т.д.) и сохраняет ключи в JSON. После того как ИИ проверил текст с заглушками, `deanonymizer.py` восстанавливает оригинальные значения в ответе нейросети.

---

## Что анонимизируется

| Категория | Пример | Токен |
|---|---|---|
| Организации (ООО, АО, ПАО...) | ООО «Рога и Копыта» | `[ОРГ_1]` |
| Организации (полная форма) | обществом с ограниченной ответственностью «...» | `[ОРГ_2]` |
| Инфраструктурные объекты | НПС «Северная» | `[ОБЪЕКТ_1]` |
| Номера договоров | договор № 123/2024 | `[ДОГОВОР_1]` |
| Названия проектов | проекта «...» / проекту: «...» | `[ПРОЕКТ_1]` |
| Месторождения и НГКМ | Таёжное месторождение | `[ОБЪЕКТ_2]` |
| Координаты | координаты: N 59°01′34″ E 73°25′42″ | `[КООРДИНАТЫ_1]` |
| Местоположение | Испрашиваемая территория расположена... | `[МЕСТО_1]` |
| ФИО | Горбунова Т.А. / Татьяна Александровна | `[ФИО_1]` |

**Не трогает:**
- Приложения (координаты в таблицах)
- Раздел «История изучения» и библиографию (там ФИО — открытая научная информация)

## Установка

### Шаг 1 — установите Python

Если Python у вас ещё нет: скачайте с [python.org](https://www.python.org/downloads/) и установите. При установке поставьте галочку **Add Python to PATH**.

Проверить, что всё прошло успешно:

```
Win + R → cmd → Enter
python --version
```

Должна появиться строка вида `Python 3.11.x`. Если появилась — всё в порядке.

### Шаг 2 — скачайте скрипты

На этой странице нажмите **Code → Download ZIP**, распакуйте в любую папку.

### Шаг 3 — установите зависимость

Откройте командную строку в папке со скриптами (в проводнике: Shift + правая кнопка → «Открыть окно PowerShell здесь»):

```bash
pip install python-docx
```

## Использование

### Анонимизация (.docx → .docx + ключи)

```bash
python anonymizer.py
```

1. Выберите файл отчёта `.docx`
2. Скрипт создаст в папке `workspace/anon/` анонимизированный файл
3. Ключи сохранятся в `workspace/keys/` — **не передавайте их вместе с отчётом**

### Деанонимизация (возврат значений)

```bash
python deanonymizer.py
```

1. Выберите текстовый файл с ответом нейросети (`.txt` или `.md`)
2. Выберите файл ключей `.json`
3. Скрипт создаст файл `*_deanon.txt` с восстановленными значениями

```
    ├── anon/      # анонимизированные файлы (в .gitignore)
    └── keys/      # файлы ключей (в .gitignore)
```

---

## Ограничения

- Работает только с `.docx` (не с PDF)
- Паттерны заточены под русскоязычные отчёты об археологических работах
- Форматирование абзацев с заменами может упроститься (если в абзаце несколько стилей)
